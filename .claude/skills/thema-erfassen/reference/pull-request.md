# Inhalt des Pull Requests

Die Beschreibung steht in `.cache/entwurf/<ID>/pr.md` und wird bei jedem Push aktualisiert.

Selbst schreibst du je Thema nur zwei, drei Sätze: Thema, Programme, Zahl der Maßnahmen und Instrumente mit ID-Bereich, nicht erfasste Programme, Pfad unter `daten/protokolle/<ID>/`. Dazu einen Satz: „KI-Entwurf für die geschlossene Testphase; menschliche Prüfung folgt (`daten/README.md` → „Prüfung“).“

Darunter `pr-daten.md` aus `npm run entwurf:bericht` **unverändert** (Modelle, Übersicht je Programm, Ohne Maßnahme, Treffer, Vergleich, Kennungen, Zuordnung, Punkte, Rückfragen, Anmerkungen der Bewertung, Kosten).

Fällt beim Erfassen eine fehlende Ursache oder eine Abgrenzungsfrage auf, die der Leitfaden nicht beantwortet, steht sie als „Offene Frage“ am Ende – sie hält den Pull Request nicht auf.
